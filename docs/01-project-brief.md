# 01 — Project Brief

## Project Name
Mian Tayyab Steel Website

## Business Name
**Mian Tayyab Steel**

## Brand Short Name
**MTS**

## Project Type
Professional industrial steel company website with a custom Next.js frontend and a manageable backend/admin system.

## Primary Objective
Build a proper commercial website for Mian Tayyab Steel that communicates trust, technical capability, product depth, and industrial credibility.

This must **not** look like a generic AI-generated or SaaS-style website.

The website should feel like it was designed specifically for an established steel and industrial materials company.

## Reference Direction
Primary reference website:

https://oht.com.pk/

The reference should be used for:
- information architecture
- product and service presentation
- application/collection landing pages
- content density
- technical information structure
- navigation
- industrial credibility
- inquiry and conversion flows

The final website should not blindly copy implementation code or visual details.

The goal is to achieve:
- a similar level of industrial authority
- clearer design
- stronger brand identity for MTS
- improved polish where appropriate

## Target Brand Positioning
Mian Tayyab Steel should be perceived as:

- established
- reliable
- technically competent
- commercially serious
- easy to contact
- capable of serving contractors, fabricators, builders, manufacturers, and industrial buyers

## Primary Audience
Potential users may include:

- construction companies
- contractors
- architects
- fabricators
- engineering firms
- manufacturers
- steel traders
- industrial buyers
- procurement teams
- infrastructure-related businesses

## Primary Website Goals

1. Present MTS products professionally.
2. Make technical product information easy to understand.
3. Help visitors discover products by use/application.
4. Build trust in the business.
5. Generate quote and WhatsApp inquiries.
6. Support SEO through product, service, and application landing pages.
7. Allow the business to manage products, services, blogs, FAQs, and inquiries without editing source code.
8. Create a premium but practical industrial design.

## Core Website Areas

Expected website areas include:

- Home
- About
- Products
- Product Detail
- Product Collections / Applications
- Services
- Service Detail
- Blog
- Blog Detail
- FAQ
- Contact
- Search
- Privacy Policy
- Terms and Conditions

## CMS / Admin Requirement
A proper admin panel is required.

The admin should manage:
- products
- product images
- specifications
- product applications
- product FAQs
- product collections
- services
- service images
- service FAQs
- blog posts
- global FAQs
- locations
- contact submissions
- quote requests
- brochures / PDFs
- global site settings
- SEO fields

## Preferred Technical Direction
Expected stack:

- Next.js
- App Router
- TypeScript
- Tailwind CSS
- Supabase PostgreSQL
- Supabase Auth
- Supabase Storage
- Vercel

Final implementation decisions must follow the full technical planning documentation.

## Critical Design Rule
Do not create a generic AI website.

Avoid:
- oversized startup-style hero copy
- meaningless gradients
- glassmorphism-heavy interfaces
- fake statistics
- repetitive 3-card layouts
- random SaaS icon sections
- excessive rounded cards
- floating decorative UI
- unnecessary animation

The website must be content-led, industrial, intentional, and commercially credible.
